# GEO Radar 확장: 경쟁사 비교 · 유료 플랜 · 알림 · 리포트 공유

네 가지 기능을 순서대로 붙입니다.

## 1. 경쟁사 비교 화면 (`/app/competitors`)
- 프로젝트에 경쟁사 도메인을 등록/삭제 (이름 + URL).
- "비교 진단 실행" 버튼: 내 사이트와 등록된 경쟁사 도메인을 같은 SEO/GEO 진단 엔진으로 돌려 점수를 저장.
- 화면 구성
  - 내 사이트 vs 경쟁사 SEO/GEO 점수 막대 비교
  - 항목별(제목, 스키마, FAQ, llms.txt 등) 통과 여부 비교 표 — 내가 지고 있는 항목 강조
  - LLM 멘션 추세: 기존 `mention_runs`에서 내 브랜드 언급률과 각 경쟁사 언급률을 날짜별 라인 차트로 나란히 표시

## 2. Stripe 유료 플랜
- 플랜: Free / Pro / Business. 월 구독(Stripe Checkout) + 고객 포털로 해지·변경.
- 플랜별 한도
  - Free: 진단 5회/월, 멘션 체크 5회/월, PDF·공유 링크 불가
  - Pro: 진단 100회/월, 멘션 체크 100회/월, PDF·공유 링크 가능
  - Business: 무제한에 가까운 한도, 팀 사용량 리포트 포함
- 사용량은 서버에서 월 단위로 집계하고, 한도 초과 시 서버 함수가 실행을 막고 업그레이드 안내를 반환합니다(프런트만 막지 않음).
- `/app/billing` 화면: 현재 플랜, 이번 달 사용량 게이지, 업그레이드/포털 버튼.

## 3. 이메일 알림 설정 (`/app/alerts`)
- 규칙 설정
  - GEO 점수가 지정한 기준(예: 70) 아래로 떨어질 때
  - LLM 멘션률이 직전 대비 N%p 이상 상승/하락할 때
- 수신 이메일, 켜기/끄기, 최소 발송 간격 설정.
- 진단·멘션 체크가 끝나는 시점에 규칙을 평가해 이메일 발송, 발송 이력 저장(중복 발송 방지).

## 4. PDF 내보내기 + 공유 링크
- 진단 리포트 화면에 "PDF 다운로드" 추가(브라우저 인쇄 대신 리포트 전용 레이아웃으로 깔끔하게 출력).
- "공유 링크 만들기": 로그인 없이 볼 수 있는 읽기 전용 링크 `/r/<토큰>` 생성. 만료일 설정과 링크 해제 가능. 공개 페이지에는 점수·요약·개선 항목만 노출하고 계정 정보는 제외.

## 기술 메모
- 새 테이블: `competitors`, `competitor_audits`, `subscriptions`, `usage_counters`, `alert_rules`, `alert_events`, `shared_reports`. 모두 사용자 소유 RLS + 필요한 GRANT. 공유 링크만 토큰 기반 익명 읽기 전용 경로로 제한.
- 진단/멘션/결제/알림 로직은 모두 TanStack 서버 함수에서 처리, Stripe 웹훅은 공개 API 라우트에서 서명 검증 후 구독 상태 갱신.
- 이메일 발송은 Lovable 이메일 기능을 사용합니다.

## 확인 필요
- Stripe 연결은 결제 설정 단계에서 키 입력이 필요합니다.
- 플랜 가격(월 요금)은 알려주시면 반영하고, 없으면 Pro 29,000원 / Business 99,000원으로 시작합니다.
