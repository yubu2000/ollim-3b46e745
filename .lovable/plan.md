# GEO/SEO 모니터링 SaaS 플랫폼

허니문 여행사(tourw.co.kr)를 시작 사례로, 내 페이지가 ChatGPT·Gemini·Claude 같은 LLM에 잘 인용되도록 진단하고, 실제 언급 여부를 추적하는 SaaS를 만듭니다.

## 사용자가 보게 될 화면

1. **랜딩 (/)** — 제품 소개, GEO/SEO 개념 설명, 무료 진단 CTA. 클린 SaaS 톤(화이트/그레이 + 블루 #2563EB).
2. **로그인/회원가입 (/auth)** — 이메일+비밀번호 계정.
3. **대시보드 (/app)** — 등록한 사이트(프로젝트)별 GEO 점수, SEO 점수, LLM 언급률 요약 카드 + 추이 그래프.
4. **진단 리포트 (/app/audit/$id)** — URL 하나를 분석해 점수와 개선 항목 목록.
   - SEO 항목: title/description, 헤딩 구조, 이미지 alt, canonical, robots/sitemap, 내부 링크, 속도 관련 힌트.
   - GEO 항목: 질문형 헤딩, FAQ/스키마(JSON-LD) 유무, 인용 가능한 사실·수치, 저자/신뢰 신호, 요약 문단, llms.txt 유무.
   - 각 항목은 통과/실패 + "왜 중요한지" + "이렇게 고치세요" 문장 포함.
5. **LLM 언급 모니터링 (/app/mentions)** — 내가 등록한 질문(예: "발리 허니문 패키지 추천")을 모델별로 실행하고, 브랜드가 언급됐는지 / 몇 번째로 언급됐는지 / 어떤 경쟁사와 함께 언급됐는지 기록. 모델별 언급률 막대·추이 그래프.
6. **콘텐츠 최적화 도우미 (/app/optimize)** — 페이지 내용을 넣으면 AI 인용에 유리한 구조로 재작성 제안 + FAQ 스키마(JSON-LD) 코드 생성(복사 가능).
7. **리포트 (/app/reports)** — 프로젝트별 종합 리포트 화면(점수 변화, 상위 개선 과제, 모델별 언급 요약).

## 데이터 (Lovable Cloud)

- `projects` — 사이트 이름, URL, 브랜드명, 소유자
- `audits` — 프로젝트별 진단 실행, seo_score / geo_score, 실행 시각
- `audit_items` — 항목별 통과 여부, 심각도, 권고 문구
- `prompts` — 추적할 질문 문장
- `mention_runs` — 질문 × 모델 실행 결과(언급 여부, 순위, 발췌, 경쟁사)
모두 로그인 사용자 본인 데이터만 보이도록 접근 제한.

## 기술 메모

- TanStack Start 서버 함수로 구현: (a) 대상 URL HTML fetch + 파싱 → 규칙 기반 SEO/GEO 채점, (b) Lovable AI(google/gemini-3.7-flash 기본)로 GEO 정성 평가와 콘텐츠 재작성, (c) 언급 추적은 여러 모델(Gemini / GPT 계열 / Claude 계열 중 게이트웨이 지원 모델)에 동일 질문을 보내 응답에서 브랜드 문자열·순위 추출 후 저장.
- 점수는 규칙 항목 가중합(0–100), 모델 판단은 근거 문장과 함께 저장해 재현 가능하게 함.
- 그래프는 Recharts, 차트는 최근 실행 이력 기준.
- 인증·데이터는 Lovable Cloud(계정, 행 단위 권한, 서버 함수 접근 제어).

## 진행 순서

1. Cloud 활성화 + 스키마/권한
2. 랜딩 + 인증 + 앱 레이아웃
3. 진단 엔진 & 리포트 화면
4. LLM 언급 추적 & 모델별 시각화
5. 콘텐츠 최적화 도우미 + 종합 리포트
6. tourw.co.kr로 실제 1회 진단 실행해 결과 확인

## 참고

- 모니터링은 "우리 앱이 모델에 질문해 응답을 관찰하는" 방식입니다. 모델 내부 인덱스를 직접 조회하는 API는 없어, 언급률은 표본 기반 추정치로 표기합니다.
- 언급 추적을 자동 주기(예: 매일)로 돌릴지는 3단계 이후에 정합니다. 우선은 수동 실행 버튼으로 시작합니다.
